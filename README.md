# 剑仙情缘恩仇录

原创 2D 武侠修仙角色扮演游戏。南宋咸淳三年元夕，临安醉春楼的跑堂阿蛰，和一壶被人换过的酒。

这是**序章《青玉案》试玩版 0.5.2**，序章十场已经做完：第一场《开坛》、第二场《行菜》、第三场《灯市》（含第一段回忆“雪夜”）、第四场《词会》、第五场《听潮阁》、第六场《十二碗面》（教学战）、第七场《一壶酒》、第八场《后巷》（第一场双人战）、第九场《屋顶》（头目战）、第十场《三天》。第一章《钗头凤》还没有开始做。

在线试玩：https://damizhoufang.github.io/jianxian/

0.5.2 的改动：
- **载入更结实了。** 0.5.1 上线后，“选一场开始”打开是空的——服务器在页面载入时对场次表那一个文件回了 503，页面没有重试，表就空着。现在 `index.html` 里有一个小载入器：脚本一个接一个执行，哪个没取到就自动重试（最多五回），实在取不到会把话写在屏幕上；音乐文件也会重试。脚本地址后面带版本号，换了版本不会和旧文件混用。版本号只在 `index.html` 里写一处。
- **上菜改成最简单的样子。** 到出菜口端一回，先送七号桌、再送九号桌，走到跟前就算，不用按键、不用挑、不会错；原来的第二轮去掉了。
- **走路不再卡桌角。** 只按着一个方向蹭到桌角、凳角时，人会自己往旁边让一让滑过去。
- **战斗给了台阶。** 屋顶那一战，每一手指令框里都有一行提示，指引开着时光标先落在建议的指令上，照着按回车就能打过去；后巷、屋顶两战输了两回以后，可以选“跳过这一战，接着看故事”。

0.5.1 的改动：左上角多了一块半透明的“下一步”提示——要做什么、补充说明、怎么做，各占一行。第二场行菜不再要人硬记：指引开着时，左上角写着哪一桌点了什么，端对了托盘就直接告诉你送到几号桌，地上的路标领到桌边；端了没人点的那盘，回出菜口按回车就能换，不扣钱（想自己记，按 H 关掉指引）。菜单多了“场次”一页，可以直接跳到任何一场的开头；游戏里随时按 `]` 跳到下一场、`[` 回上一场；标题画面也有“选一场开始”。菜单现在在对白、演出、战斗里都能打开。

0.5.0 的改动：序章接到结尾。第八场从后厨后门逃进后巷，惊蛰和夏离并肩打三个黑衣人，时令轮从这里开始转；第九场在屋顶对上蟹壳青——铁臂打不动，要闪开重拳把他一步步引到灯索上；第十场是屋顶被围、堂上具保、二楼栏杆边的一问一答，和御街上的回头一眼。新增后巷、屋顶两个场景。战斗里指令刚弹出来的一瞬不收回车，免得连按对白时误选。

0.4.0 的改动：有了战斗——行动条排先后，敌人的下一手先露架势，挡还是闪由你定；第六场听雪出场，是第一场教学战（不能还手，撑过三个回合）；第七场是那壶毒酒，有雁翎铜符和壶盖两个特写。

0.3.0 的改动：八位重点配角（范醉翁、贺元度、重玄子、阮四娘、老褚、阿桂、蟹壳青、钟推官）有了立绘和表情头像，图鉴分成主角、配角、配乐三组；新增二楼回廊与三楼听潮阁两个场景，序章接到第五场。

0.2.0 的改动：四位主角各有单独绘制的立绘、带表情的对话头像、场景里的行走与动作；标题画面和菜单里多了“人物图鉴 · 配乐”；配乐从三首加到九首，各场景各用各的；画面整体调亮、四边不再压黑；对话框缩小三成并改成半透明（亮度和透明度都能在设置里调）。

## 怎么玩

用 Chrome 打开 `index.html`（双击即可，不需要服务器），或者放到 GitHub Pages 上直接访问。

| 按键 | 作用 |
| --- | --- |
| 方向键 | 朝四个固定方向走 |
| W / A / D / S | W 前进，A、D 转向（按住不放就朝新方向走），S 掉头往回走。菜单里可改成普通的四向 |
| 回车、空格、E | 互动；对白往下 |
| H | 开关地上的路线指引 |
| V | 俯瞰全场（上帝视角）；俯瞰时点地面，人自己走过去 |
| F | 全屏 |
| Esc | 菜单：人物、设置、存档、场次；“功力全开”和“人物图鉴 · 配乐”在人物页。对白、演出、战斗里也能开 |
| ] 和 [ | 测试用：跳到下一场／回上一场的开头（菜单“场次”页里可以点任何一场） |
| 战斗中 | ← → 或数字键选指令，回车定；右下角写着对手下一手的架势，上方是行动先后，右上是时令轮。输了从这一场战斗开头重来 |

进度在每一场开头自动保存，存在浏览器里。

## 目录

```
index.html          页面与界面样式
src/core.js         画布缩放、输入、主循环
src/paint.js        画法库：木纹、石板、灯、酒坛、桌椅等
src/figures.js      场景里的人物：参数化的矢量小人，四个朝向，手里能拿东西
src/portraits.js    主角的脸与对话头像（带表情）
src/portraits2.js   主角的全身立绘
src/portraits3.js   重点配角的立绘与头像（皱纹、胡须、常用姿势和小道具也在这里）
src/world.js        场景、镜头、碰撞、寻路、路线指引、俯瞰、灯光
src/scenes1.js      酒窖、后厨
src/scenes2.js      一楼大堂、门首御街、雪夜街
src/scenes3.js      二楼回廊（词会）、三楼听潮阁、后巷、屋顶
src/ui.js           对白、字幕、题词、菜单、标题
src/gallery.js      人物图鉴与配乐试听
src/battle.js       战斗：行动条、时令轮、指令、架势预告（每场战斗是一份定义，写在 story.js 的演出里）
src/story.js        剧本解释器与各场演出
src/audio.js        声音播放
data/prologue.js    序章剧本（纯文本）
data/checkpoints.js 各场开头的进度快照，跳场用；由 tools/checkpoints.js 生成，改了剧本或演出里的旗标要重新生成
music/*.js          离线合成好的音乐与音效（Ogg Vorbis，包成脚本以便双击打开也能播放）
tools/music.py      音乐的合成程序：python3 tools/music.py
tools/play.js       自动从头玩一遍的检查脚本
tools/loadtest.js   起一个本地网页服务，故意让某个文件头几回回 503，看载入器能不能扛过去
tools/servetest.js  用真方向键、只照着地上的路标走，把第二场的菜送完
tools/checkpoints.js 自动通玩一遍，重新生成 data/checkpoints.js
tools/jumptest.js   逐场跳过去再自动走到下一场，看十份快照都接得上
tools/galtest.js    图鉴与九首配乐的检查脚本
tools/battletest.js 用真按键打一场战斗，输了会按提示重来：node tools/battletest.js "第八场　后巷"（或 "第六场　十二碗面"、"第九场　屋顶"）
tools/battlesim.js  把一场战斗照实掷骰连打几十遍，看胜率和剩下的气血：node tools/battlesim.js roof 战三 60
tools/entertest.js  用真回车把没有战斗的一场从存档点按到底：node tools/entertest.js "第十场　三天"
tools/capture.js    从某一场的存档点起慢速自动走，逐拍截图（看演出用）
```

## 续写剧本

剧本在 `data/` 下，一行一拍：`== 场名 ==` 是一场的开头和存档点；`名字：台词` 是对白，主角可以带表情，写成 `陆惊蛰[笑]：台词`；`*文字*` 是旁白；`@指令` 是给程序的记号（见 `src/story.js` 顶上的说明）。新的一章就是新的一份剧本，加上它用到的场景和演出。

## 画面与音乐

画面全部由程序绘制，没有图片文件，按屏幕实际像素渲染（4K 屏上是 3840×2160）。
音乐是原创旋律，用 `tools/music.py` 里的拨弦、管乐与打击乐模型离线合成成整首音频；游戏里只播放，不做即时合成。

| 曲子 | 用在哪里 | 气质 |
| --- | --- | --- |
| 《惊蛰》 | 标题画面、听潮阁、序章结尾的御街 | 主题。箫与筝，宫调慢板 |
| 《开坛》 | 酒窖 | 古琴、阮、箫，商调，不紧不慢 |
| 《灶火》 | 后厨 | 笛、琵琶、板、小锣，徵调快板 |
| 《元夕》 | 一楼大堂；二楼隔着楼板也听得见 | 笛、琵琶、筝、板鼓，主题的快板变奏 |
| 《灯市》 | 门首御街 | 锣鼓、笛、筝，宫调 |
| 《雪夜》 | 回忆 | 箫与古琴，羽调，留白 |
| 《暗流》 | 不对劲的时候（老酒鬼的警告、贺元度看见那把刀）；后巷、屋顶 | 低箫、古琴、鼓 |
| 《阑珊》 | 第四场，阑珊唱《青玉案》 | 琵琶轮指、箫，羽调慢板 |
| 《交锋》 | 战斗（第六、八、九场） | 大鼓、钹、琵琶扫弦、笛，羽调急板 |

地址后面加 `#gallery` 可以直接打开图鉴；加 `#alley`、`#roof` 等场景名可以直接进那个场景走走（调试用）。

## 上线到 GitHub Pages

把整个文件夹推到一个公开仓库，在仓库的 Settings → Pages 里选 main 分支根目录，几分钟后即可访问。
