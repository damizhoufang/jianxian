# 剑仙情缘恩仇录

原创 2D 武侠修仙角色扮演游戏。南宋咸淳三年元夕，临安醉春楼的跑堂阿蛰，和一壶被人换过的酒。

这是**试玩版 0.8.0**：序章《青玉案》十场、第一章《钗头凤》十二场，都做完了。

0.8.0 的改动：第一章的后五场，外加三首白天的曲子。
- **第八场 架阁库。** 新场景：临安府存旧案卷的库房。提着灯绕过架子往最里头走；巡更的灯笼从窗外过的时候，阿蛰自己会掩灯蹲下——不用按键，也不会失败。两个特写：摊开的那一卷案卷，和信上那一笔往上挑的捺。
- **第九场 湖上。** 新场景：夜里的西湖。这一段是撑船——方向键和走路一样，别的灯船绕过去就行；按 V 俯瞰，连成一片、挂红灯的就是要去的画舫，水面上的金色路标一路领过去。
- **第十场 梅花翅。** 新场景：平章的画舫。第一章的首领战：她在两条小船之间跳，站稳的时候够不着；她要跳船，就把船晃起来，她落脚不稳，两个人一起打。每一手指令框里都写着该用哪一个，指引开着时光标先落在上面，照着按回车就能赢，而且一下都不会挨（这一场的镖，踏潮步总躲得开）。输两回可以跳过。
- **第十一场 公堂。** 新场景：临安府公堂。阑珊走上堂。
- **第十二场 开个价。** 回到醉春楼和软红院，章末。
- **三首新曲**，都给白天的临安：《市声》（筝、阮、碰铃，徵调，没有鼓——府衙门外、白天的醉春楼）、《瓦子》（琵琶和锣鼓一问一答，商调快板——北瓦）、《梅窗》（古琴、箫，宫调慢板——软红院、仁寿堂、公堂散后）。
- 另外：添了三样音效（一声弦、梆子、水声）；路线指引关着的时候，左上角最后一行一律提醒“按 H 打开”；战斗里的招式可以带一段出手之前的动作（暗器飞过去）。

0.7.0 的改动：第一章接着做了四场。
- **第四场 团头。** 新场景北瓦（茶棚、说话和傀儡的勾栏、相扑露台）。团头老癞认出当年的阿蛰，给了一条线索；听雪溜出来打擂，第七场相扑由你替她打——只有“闪”“摔”两手，每一手指令框里都写着该用哪一个，指引开着时光标先落在上面，照着按四回回车就赢。输两回可以跳过。
- **第五场 软红院。** 新场景阑珊临水的小楼。对句：墙上半首词，两回各从三句里挑一句，挑错了她只说一句、那一句拿掉再挑，不罚；指引开着时光标先落在对的那一句上。之后有一处选择（怎么求她），三样都能往下走，只记一笔好感。
- **第六场 忆二·抄家。** 新场景十一年前的陆家书房（旧绢色调），可以走：先到父亲的书案前，再从后门出去。两个特写：新书上钤的“老学庵”印、火把底下翻书的一只手。
- **第七场 一方印。** 回到软红院，三句话。
- 另外：剧情正等着你去找的那个人，现在优先于旁边会搭话的路人（原来走到团头跟前，回车会被他脚边数钱的小乞儿抢去）；选择框的问题有了深色的底，刚弹出来的一瞬不收回车；战斗收场镜头拉远的那一瞬不再露出场景外面的黑边；对白换句时不再闪一下上一句的字。

0.6.0 的改动：开始做第一章。序章演完不再停下，接着就是第一章；新增两个场景——清晨的临安府衙门外、清河坊仁寿堂药铺；后厨多了一段调查（泔水桶里的真壶）和一段回想（昨夜楼梯拐角的那一下擦肩）；药铺白墙上有一处题壁可以看。各章剧本各放一个文件（`data/prologue.js`、`data/chapter1.js`），启动时接成一本；菜单“场次”页按章分组。另外：万一人被摆进了桌子的占位里，现在走得出来。

0.5.2 的改动：
- **载入更结实了。** 0.5.1 上线后，“选一场开始”打开是空的——服务器在页面载入时对场次表那一个文件回了 503，页面没有重试，表就空着。现在 `index.html` 里有一个小载入器：脚本一个接一个执行，哪个没取到就自动重试（最多五回），实在取不到会把话写在屏幕上；音乐文件也会重试。脚本地址后面带版本号，换了版本不会和旧文件混用。版本号只在 `index.html` 里写一处。
- **上菜改成最简单的样子。** 到出菜口端一回，先送七号桌、再送九号桌，走到跟前就算，不用按键、不用挑、不会错；原来的第二轮去掉了。
- **走路不再卡桌角。** 只按着一个方向蹭到桌角、凳角时，人会自己往旁边让一让滑过去。
- **战斗给了台阶。** 屋顶那一战，每一手指令框里都有一行提示，指引开着时光标先落在建议的指令上，照着按回车就能打过去；后巷、屋顶两战输了两回以后，可以选“跳过这一战，接着看故事”。

0.5.1 的改动：左上角多了一块半透明的“下一步”提示——要做什么、补充说明、怎么做，各占一行。第二场行菜不再要人硬记：指引开着时，左上角写着哪一桌点了什么，端对了托盘就直接告诉你送到几号桌，地上的路标领到桌边；端了没人点的那盘，回出菜口按回车就能换，不扣钱（想自己记，按 H 关掉指引）。菜单多了“场次”一页，可以直接跳到任何一场的开头；游戏里随时按 `]` 跳到下一场、`[` 回上一场；标题画面也有“选一场开始”。菜单现在在对白、演出、战斗里都能打开。

0.5.0 的改动：序章接到结尾。第八场从后厨后门逃进后巷，惊蛰和夏离并肩打三个黑衣人，时令轮从这里开始转；第九场在屋顶对上蟹壳青——铁臂打不动，要闪开重拳把他一步步引到灯索上；第十场是屋顶被围、堂上具保、二楼栏杆边的一问一答，和御街上的回头一眼。新增后巷、屋顶两个场景。战斗里指令刚弹出来的一瞬不收回车，免得连按对白时误选。

0.4.0 的改动：有了战斗——行动条排先后，敌人的下一手先露架势，挡还是闪由你定；第六场听雪出场，是第一场教学战（不能还手，撑过三个回合）；第七场是那壶毒酒，有雁翎铜符和壶盖两个特写。

0.3.0 的改动：八位重点配角（范醉翁、贺元度、重玄子、阮四娘、老褚、阿桂、蟹壳青、钟推官）有了立绘和表情头像，图鉴分成主角、配角、配乐三组；新增二楼回廊与三楼听潮阁两个场景，序章接到第五场。

0.2.0 的改动：四位主角各有单独绘制的立绘、带表情的对话头像、场景里的行走与动作；标题画面和菜单里多了“人物图鉴 · 配乐”；配乐从三首加到九首，各场景各用各的；画面整体调亮、四边不再压黑；对话框缩小三成并改成半透明（亮度和透明度都能在设置里调）。

## 怎么玩

用 Chrome 打开 `index.html`（双击即可，不需要服务器），或者放到 GitHub Pages 上直接访问。

| 按键 | 作用 |
| --- | --- |
| 方向键 | 朝四个固定方向走 |
| W / A / D / S | W 前进，A、D 转向（按住不放就朝新方向走），S 掉头往回走。菜单里可改成普通的四向 |
| 回车、空格、E | 互动；对白往下 |
| H | 开关地上的路线指引 |
| V | 俯瞰全场（上帝视角）；俯瞰时点地面，人自己走过去 |
| F | 全屏 |
| Esc | 菜单：人物、设置、存档、场次；“功力全开”和“人物图鉴 · 配乐”在人物页。对白、演出、战斗里也能开 |
| ] 和 [ | 测试用：跳到下一场／回上一场的开头（菜单“场次”页里可以点任何一场） |
| 战斗中 | ← → 或数字键选指令，回车定；右下角写着对手下一手的架势，上方是行动先后，右上是时令轮。输了从这一场战斗开头重来 |

进度在每一场开头自动保存，存在浏览器里。

## 续写剧本

剧本在 `data/` 下，一行一拍：`== 场名 ==` 是一场的开头和存档点；`名字：台词` 是对白，主角可以带表情，写成 `陆惊蛰[笑]：台词`；`*文字*` 是旁白；`@指令` 是给程序的记号（见 `src/story.js` 顶上的说明）。新的一章就是新的一份剧本，加上它用到的场景和演出。

## 画面与音乐

画面全部由程序绘制，没有图片文件，按屏幕实际像素渲染（4K 屏上是 3840×2160）。
音乐是原创旋律，用 `tools/music.py` 里的拨弦、管乐与打击乐模型离线合成成整首音频；游戏里只播放，不做即时合成。

## 上线到 GitHub Pages

把整个文件夹推到一个公开仓库，在仓库的 Settings → Pages 里选 main 分支根目录，几分钟后即可访问。
